## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Leer `.cu8` como `complex` | File Source complex interpretaba bytes CU8 como complex64 y producía datos inválidos | advisory | File Source apunta solo a `fm_muestra.cfile`; convertir CU8 explícitamente antes de usarlo |
| Python generado desincronizado | `test.py` había omitido el Throttle presente en el GRC | advisory | Tratar `test.grc` como fuente y regenerar con GNU Radio 3.10.12 después de cada edición |
| Cuenta GitHub equivocada | El push devolvió 403 porque estaba activa la cuenta `ollerenac` | advisory | Ejecutar `gh auth status` y confirmar `ollerenac-uni` antes de todo push |
| Cachés fuera del sandbox | El smoke test falló al intentar escribir la caché FFTW en `~/.cache` | advisory | Para pruebas aisladas, definir XDG_CACHE_HOME y MPLCONFIGDIR dentro de `/tmp` |
| Saltar la puerta de sesión | S02 se abriría con S01 todavía en revisión | advisory | No crear S02 mientras S01 conserve `status: draft` |
| Incluir binarios incidentales | Hay dos PDFs locales sin seguimiento que no forman parte del trabajo aprobado | advisory | Preparar commits con rutas explícitas y revisar `git diff --cached --name-status` |
