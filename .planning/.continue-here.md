## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Saltar la puerta de sesión | S02 se abriría con S01 aún en revisión | advisory | Antes de crear `docs/sessions/02-*/`, comprobar que `docs/sessions/01-introduccion-sdr/index.md` ya no tiene `status: draft`. Regla escrita al final de `docs/plans/2026-09-05-curso-sdr.md`. |
| `mkdocs build` desde subcarpeta | Se ejecutó desde `figures/` y falló con exit 1 sin mensaje útil (no encontró `mkdocs.yml`) | advisory | Ejecutar siempre `mkdocs build --strict` desde la raíz del repo, o con `-f mkdocs.yml`. |
| `gnuradio.__version__` | La guía publicó un comando de verificación que no existe; el profesor lo detectó al probar | advisory | Verificación correcta: `python -c "from gnuradio import gr; print(gr.version())"` o `gnuradio-config-info --version`. Probar cada comando de las guías en `~/radioconda/bin/` antes de publicarlo. |
| Premisa técnica sin verificar | Se asumió que VirtualBox necesita el Extension Pack para USB 2.0/3.0; falso desde VirtualBox 7.0 (2022). Lo detectó el agente adversario | advisory | Todo hecho técnico que entre en una guía se contrasta con fuente primaria (changelog, README oficial, datasheet). Las fuentes ya verificadas están listadas en el diseño. |
| URL local sin prefijo | Las páginas del `mkdocs serve` del profesor dan 404 en `/setup/`; viven en `/sdr/setup/` porque `site_url` tiene ruta | advisory | Usar siempre `http://127.0.0.1:9000/sdr/...` al enlazar o verificar en local. |
| `import gnuradio.rds` | gr-rds de radioconda se importa como `import rds` (nivel superior), no `gnuradio.rds`; una prueba mal escrita lo dio por ausente | advisory | Para módulos OOT en radioconda comprobar el nombre real con `ls ~/radioconda/lib/python3.12/site-packages/`. |
| Usuario de GitHub equivocado | El primer push fue a `ollerenac/sdr` (cuenta equivocada); quedó un repo huérfano público | advisory | Cuenta correcta: `ollerenac-uni` (activa en `gh auth status`). El repo huérfano sigue existiendo hasta que el profesor decida borrarlo. |
